## 3. Fetish タグ判定仕様

各タグは該当設問のスコアが閾値を超えた場合に付与される。
NTR は「まあ当てはまる（スコア1）」以上の1問でも該当すれば即時判定。

| カテゴリ | タグ一覧 |
|---------|---------|
| 道具系 | 縄、鞭、レザーやラバー、蝋燭 |
| 人体系 | 体液（血以外広義）、声、匂い、人間の部位、血 |
| モラル系 | 露出、羞恥、落書き、NTR ※1問「まあ当てはまる（スコア1）」以上で即時判定 |
| 拘束系 | 手錠、マミー |
| その他 | くすぐり、首絞め |

## 4. 判定ロジック

### メインタイプ・サブタイプ

- 4軸の結果を組み合わせて 12 タイプのうち最もスコアが近い2タイプを選出する
- メインタイプ：スコア上位1位
- サブタイプ：スコア上位2位

### スイッチャー判定

- メインタイプとサブタイプで **Lead と Follow の両方が出た**場合 → **スイッチャー** と表示する

### レアリティ表示

- 「あなたのタイプは全体の○○%」と表示する
- 初期値はタイプごとに固定値（実ユーザーデータ蓄積後に動的値に切り替え可）

## 6. Luna 導線

### 相性提案
「今、Luna にはこのタイプのユーザーが〇〇人登録しています」と結果画面に表示する。

### メールアドレス入力フォーム
結果保存用のメアド入力フォームを結果画面に設置する。

> **実装状況（v1.0）:** フォームUIは実装済み。バックエンド保存処理（メール送信・DB登録）は初期リリーススコープ外とし、次フェーズで実装する。

### プロフ自動生成 AI ボタン
- 結果画面に「診断結果を Luna の自己紹介文に変換する」ボタンを設置する
- ボタン押下で Claude API を呼び出し、タイプ・Fetish タグをもとに自己紹介文を生成する
- 生成文をそのまま Luna の自己紹介欄に設定できる導線を用意する

## 7. 非機能要件

| 項目 | 要件 |
|------|------|
| デザイン | 綺麗系・高級感（Lunaブランドに合わせる） |
| SNS シェア | OGP 画像生成（タイプ名・コード表示）、Twitter/X・LINE 対応 |
| レスポンシブ | スマートフォンファースト |
| セキュリティ | OWASP Top 5 準拠、入力バリデーション必須 |
